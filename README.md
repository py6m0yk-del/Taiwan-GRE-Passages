## 📖 Project Overview

**Formosa Lexicon** is an advanced English reading curriculum designed for GRE test-takers and scholars of international relations. The collection contextualizes all **4,990 deduplicated high-frequency GRE words** into **100 analytical reading passages** written in rigorous GRE style (analogous to the *New York Review of Books*, *The Economist*, and academic jurisprudence journals).

Every passage centers on **Taiwan (Formosa)**—exploring its democratic evolution, semiconductor shield, geopolitical dilemmas, constitutional jurisprudence, indigenous heritage, biodiversity, and civil society resilience from a pro-democracy, sovereign perspective.

---

## ✨ Key Interactive Document Features

Each passage is packaged as a fully interactive Microsoft Word (`.docx`) file with bidirectional navigation:

1. **Exact 4-Paragraph Analytical Structure**: Standardized to ~400–480 words across exactly 4 paragraphs.
2. **Visual Target Word Highlighting**: Target GRE vocabulary words are styled in **`#0969DA` bold underline**.
3. **Native Hover ScreenTips**: Hovering the cursor over any highlighted word pops up its clean GRE definition.
4. **Single-Click Instant Navigation**: Left-clicking any target word immediately jumps to its detailed entry in the Glossary Table at the bottom of the document (optimized for macOS Microsoft Word single-click).
5. **Bidirectional `[↩ Return]` Jump**: Clicking `[↩ Return]` in the vocabulary table returns immediately to the exact passage sentence where the word was read.
6. **Native Word Review Pane**: Review comments are embedded in the document margin for side-by-side study.

## 🛠️ Reproduction & Architecture

The passages were generated and validated using semantic clustering and automated OpenXML injection:
- **`gre_5000_words_complete.json`**: Complete deduplicated dataset of 4,990 high-frequency GRE words with definitions.
- **`clusters_100.json`**: 100 semantically cohesive clusters derived via BERT subword embeddings and k-NN clustering.
- **`passage_builder.py`**: Python script utilizing `python-docx` and low-level XML manipulation to build bidirectional bookmarks (`w:bookmarkStart`, `w:bookmarkEnd`), ScreenTip tooltips (`w:tooltip`), and internal hyperlinks (`w:hyperlink`).
